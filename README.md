# AASR 33 Inspector

Standalone HTML tool for recording attendance and administrative acts for the AASR workshops:

- «Μυσταγωγία» υπ' αρ. 5
- «Φως» υπ' αρ. 14

## Features

- Preloaded meeting dates
- Attendance count per date
- Multiple administrative act choices
- Free-text notes
- Local browser saving
- CSV and JSON export/import
- Print / Save as PDF
